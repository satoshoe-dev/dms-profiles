# Profiles: ステップごとの手順

[English](GUIDE.md) · [Deutsch](GUIDE.de.md) · [Español](GUIDE.es.md) · [Français](GUIDE.fr.md) · [Italiano](GUIDE.it.md) · [Português](GUIDE.pt.md) · [Русский](GUIDE.ru.md) · **日本語** · [简体中文](GUIDE.zh_CN.md)

## 1. プラグインをインストールして有効にする

プラグインレジストリから:

```sh
dms plugins install dmsProfiles
```

DMS の 設定 → プラグイン → ブラウズ からも入手できます。または、リポジトリを DMS のプラグインフォルダーにクローンします。

```sh
git clone https://github.com/satoshoe-dev/dms-profiles ~/.config/DankMaterialShell/plugins/DmsProfiles
```

設定 → プラグイン を開き、Profiles をオンにします。

![Profiles が表示されたプラグイン一覧](images/01-plugin-list.png)

## 2. 最初のプロファイルを作成する

テーマ、アクセントカラー、壁紙、バー、フレームなど、シェルを好みの状態に整えます。次にプラグイン一覧で Profiles を展開し、名前を入力して「作成」をクリックします。

![プロファイルの作成](images/02-create.png)

新しいプロファイルはすぐに有効になります。その後に変更した内容は、数秒後にそのプロファイルへ保存されます。

## 3. 2 つ目を作成する

壁紙やアクセントカラーを変えるなどして見た目を変更し、同じ手順で 2 つ目のプロファイルを作成します。以降の変更は 2 つ目のプロファイルに保存され、1 つ目はそのまま残ります。

## 4. 選択画面用のキーバインドを追加する

niri では、設定ファイルに次を追加します。

```kdl
binds {
    Mod+Shift+M { spawn "dms" "ipc" "call" "profiles" "toggle"; }
}
```

## 5. 切り替える

キーバインドを押し、マウスホイールまたは矢印キーでプロファイルを選び、Enter を押すかクリックします。

![カルーセル表示の選択画面](images/03-picker-carousel.png)

キャプチャの間だけ画面が一瞬止まります。その後トランジションで新しいプロファイルの壁紙に移り、DMS がプロファイルを適用し終えると、バー、フレーム、ウィンドウ、ウィジェットがフェードインします。独自の壁紙がないプロファイルでは、代わりにトランジションで完成したデスクトップが現れます。

![トランジションの途中](images/04-transition.png)

## 6. 選択画面の見た目を選ぶ

「プロファイル選択」で、表示形式（ストリップ、フリー、カルーセル、グリッド）とプレビューの形状を選びます。

![選択画面の設定](images/05-picker-settings.png)

![六角形のグリッド](images/06-picker-grid.png)

## 7. トランジションを選ぶ

「トランジション」で種類を選ぶか、「ランダム」のままにします。ランダムの場合は、使いたい種類をクリックします。「時間」でアニメーションの長さを決めます。初期値は 1200 ms です。「トランジションを試す」では、切り替えずにアニメーションを 1 回再生し、元の画面はグレーで表示されます。

![トランジションの設定](images/07-transition-settings.png)

## 8. プロファイルを管理する

プラグイン設定の上部にある一覧には、プロファイルの適用、名前の変更、上下への移動、削除を行うボタンがあります。アクティブなプロファイルの横にある元に戻すボタンで、有効にした時点の状態に戻せます。各プロファイル名の下のフォルダー行で、壁紙ピッカー（`dms ipc call profiles wallpapers`）が開くフォルダーを設定します。クリックで選択、横の×で解除です。

![プロファイル一覧](images/08-list.png)

## 9. プロファイルにプラグインの設定を含める（任意）

ほかのプラグインの設定をプロファイルごとに保持するには、「プロファイルと一緒に保存するプラグイン」にその ID を入力します。例: `audioFx`

## 10. DMS 以外の設定（任意）

「詳細設定」では、端末の色など DMS が管理しない設定のために、保存コマンドと適用コマンドを指定できます。コマンドが受け取る内容と例については README を参照してください。
