# Profiles: шаг за шагом

## 1. Установите и включите плагин

Из реестра плагинов:

```sh
dms plugins install dmsProfiles
```

Плагин также есть в каталоге DMS: Настройки → Дополнения. Или клонируйте репозиторий в папку плагинов DMS:

```sh
git clone https://github.com/satoshoe-dev/dms-profiles ~/.config/DankMaterialShell/plugins/DmsProfiles
```

Откройте Настройки → Дополнения и включите Profiles.

![Список плагинов с Profiles](images/01-plugin-list.png)

## 2. Создайте первый профиль

Настройте оболочку так, как вам нравится: тема, акцентный цвет, обои, панель, рамка. Затем разверните Profiles в списке плагинов, введите имя и нажмите «Создать».

![Создание профиля](images/02-create.png)

Новый профиль сразу становится активным. Всё, что вы измените потом, через несколько секунд сохраняется в нём.

## 3. Создайте второй

Измените внешний вид, например поставьте другие обои и другой акцентный цвет, и создайте второй профиль тем же способом. Теперь изменения попадают во второй профиль, а первый остаётся таким, каким был.

## 4. Назначьте горячую клавишу для выбора профиля

В niri добавьте в конфигурацию:

```kdl
binds {
    Mod+Shift+M { spawn "dms" "ipc" "call" "profiles" "toggle"; }
}
```

## 5. Переключитесь

Нажмите горячую клавишу, выберите профиль колесом мыши или клавишами со стрелками и нажмите Enter или щёлкните по нему.

![Выбор профиля в виде карусели](images/03-picker-carousel.png)

Пока экран снимается, он на мгновение замирает. Затем переход идёт к обоям нового профиля, а панели, рамка, окна и виджеты плавно появляются, как только DMS применил профиль. Если у профиля нет собственных обоев, переход вместо этого открывает готовый рабочий стол.

![Переход в процессе](images/04-transition.png)

## 6. Выберите вид окна выбора

В разделе «Выбор профиля» выберите вид (лента, свободно, карусель или сетка) и форму превью.

![Настройки выбора профиля](images/05-picker-settings.png)

![Сетка с шестиугольниками](images/06-picker-grid.png)

## 7. Выберите переход

В разделе «Переход» выберите тип или оставьте «Случайный». Для случайного перехода щёлкните по типам, которые хотите разрешить. «Длительность» задаёт, сколько идёт анимация, по умолчанию 1200 мс. «Попробовать переход» один раз проигрывает анимацию без переключения, старое изображение при этом показано серым.

![Настройки перехода](images/07-transition-settings.png)

## 8. Управляйте профилями

В списке вверху настроек плагина есть кнопки, чтобы применить, переименовать, переместить вверх или вниз и удалить профиль. Кнопка отмены рядом с активным профилем возвращает состояние, которое у него было при активации. Строка с папкой под названием каждого профиля задаёт папку, в которой открывается выбор обоев (`dms ipc call profiles wallpapers`): щелчок — выбрать, крестик рядом — сбросить.

![Список профилей](images/08-list.png)

## 9. Настройки плагинов в профиле (необязательно)

Чтобы хранить настройки другого плагина отдельно для каждого профиля, укажите его id в поле «Плагины, сохраняемые в профиле», например `audioFx`.

## 10. Настройки вне DMS (необязательно)

В разделе «Дополнительно» можно задать команду сохранения и команду применения для настроек, которыми DMS не управляет, например цветов терминала. Что получают эти команды, описано в README, там же есть пример.
