# Profiles

[English](README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Português](README.pt.md) · **Русский** · [日本語](README.ja.md) · [简体中文](README.zh_CN.md)

Плагин для [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell), который сохраняет внешний вид оболочки под именем и позволяет переключаться между такими вариантами. Профиль хранит тему и акцентный цвет, светлый или тёмный режим, обои, панели, рамку, прозрачность, шрифты, анимации и виджеты рабочего стола вместе с их расположением.

![Profiles](assets/screenshot.png)

Пошагово с картинками: [руководство по установке и настройке](docs/GUIDE.ru.md).

## Переключение

Откройте окно выбора горячей клавишей и выберите профиль. Пока экран снимается, он на мгновение замирает (примерно 0,2 с). Затем переход сразу идёт от старого изображения к обоям нового профиля. Тем временем DMS применяет профиль, и когда он готов, панели, рамка, окна и виджеты плавно появляются поверх новых обоев. Как оболочка перестраивается по частям, не видно.

Профили без собственных обоев используют прежний порядок: снятое изображение остаётся на экране, пока профиль не применён, а затем переход открывает готовый рабочий стол. Длительность перехода задаётся в настройках (по умолчанию 1,2 с).

На выбор 29 переходов, среди них затухание, шторка, круг, двери, жалюзи, таяние, осколки, выключение кинескопа, снег на экране и пять хакерских эффектов. Случайный режим можно ограничить теми переходами, которые нравятся. У большинства анимаций край светится акцентным цветом нового профиля.

## Выбор профиля

Окно выбора бывает четырёх видов: лента на подложке, та же лента без подложки, карусель с текущим профилем крупно в центре и сетка на весь экран. Превью могут быть вертикальными, горизонтальными, квадратными, круглыми, шестиугольными, ромбовидными или наклонными (вертикальные, с наклонной рамкой). В сетке шестиугольники и ромбы выкладываются сотами с тем же зазором, что и у окон. Обводку, свечение, галочку и радиус скругления можно отключить или настроить.

Колесо мыши и стрелки перемещают выбор, Enter или щелчок применяет профиль, Escape закрывает окно.

## Сохранение

Изменения в настройках DMS через несколько секунд сохраняются в активный профиль. Каждый профиль помнит, как он выглядел в момент активации, поэтому изменения можно отменить на странице настроек. Обои копируются в профиль, так что перемещение или удаление исходного файла ему не вредит.

Профили лежат в `~/.config/DankMaterialShell/profiles/`, по одной папке на профиль.

## Настройки других плагинов

Настройки плагинов тоже могут входить в профиль. Укажите ID плагинов в разделе Настройки → Дополнения → Profiles → Плагины, сохраняемые в профиле, например `audioFx`.

## Всё, что вне DMS

Цвета терминала, темы браузера или правила композитора, которыми DMS не управляет, можно обработать двумя необязательными командами:

- Команда сохранения выполняется при сохранении профиля. JSON, который она выводит, сохраняется в профиле как `extras`.
- Команда применения выполняется во время переключения, сразу после записи новых настроек. Новый рабочий стол появляется только после её завершения. Она получает `DMS_PROFILE_DIR`, `DMS_PROFILE_SLUG`, `DMS_PROFILE_NAME` и `DMS_PROFILE_NEW_COLORS` (1, если генерируются новые цвета). Файл профиля: `$DMS_PROFILE_DIR/profile.json`.

Небольшой пример, который хранит шрифт интерфейса GTK для каждого профиля:

```sh
# save command
printf '{"font": "%s"}' "$(gsettings get org.gnome.desktop.interface font-name | tr -d "'")"

# apply command
gsettings set org.gnome.desktop.interface font-name \
  "$(python3 -c 'import json,os; print(json.load(open(os.environ["DMS_PROFILE_DIR"] + "/profile.json"))["extras"]["font"])')"
```

## Требования

DankMaterialShell 1.6.1 или новее. Для перехода экран снимается через `grim`, если он установлен, иначе через `dms screenshot`, который входит в DMS. Сам я пользуюсь плагином в niri. Отступы между окнами, радиус скругления и толщину рамки DMS сам записывает в конфигурацию композитора, так что и на других композиторах, которые поддерживает DMS, они должны следовать профилю.

## Установка

Из реестра плагинов:

```sh
dms plugins install dmsProfiles
dms ipc call plugins enable dmsProfiles
```

Плагин также есть в каталоге DMS: Настройки → Дополнения. Установка из репозитория:

```sh
git clone https://github.com/satoshoe-dev/dms-profiles ~/.config/DankMaterialShell/plugins/DmsProfiles
dms ipc call plugins enable dmsProfiles
```

Затем добавьте горячую клавишу, например в niri:

```kdl
Mod+Shift+M { spawn "dms" "ipc" "call" "profiles" "toggle"; }
```

## IPC

```sh
dms ipc call profiles toggle
dms ipc call profiles list
dms ipc call profiles apply <slug>
dms ipc call profiles create <name>
dms ipc call profiles save
dms ipc call profiles rename <slug> <new name>
dms ipc call profiles remove <slug>
dms ipc call profiles move <slug> left|right|<position>
dms ipc call profiles reset <slug>
dms ipc call profiles previewTransition <type>
dms ipc call profiles status
```

## Переводы

Плагин доступен на немецком, испанском, французском, итальянском, португальском, русском, японском и упрощённом китайском и использует язык, выбранный в DMS. Если перевод звучит неправильно, pull request приветствуется.
